# 3D-проволочное яблоко

Небольшое Java Swing-приложение, которое строит и отображает каркасную 3D-модель яблока. Проект демонстрирует аффинные преобразования: перенос, вращение, масштабирование и проекцию на экран.

## Сборка и запуск

Потребуется JDK 8 или новее. Из корня проекта выполните:

```bash
javac -d bin src/*.java
java -cp bin App
```

## Управление

- ЛКМ — перемещение по оси X с качением;
- ПКМ — вращение по осям X и Y;
- `Shift` + ЛКМ — вращение по оси Z;
- `Ctrl` + ЛКМ / `Alt` + ЛКМ — перемещение по осям Y / Z;
- колесо мыши — изменение масштаба.
